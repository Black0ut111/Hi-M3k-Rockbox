## Hi-M3K

适用于 FiiO M3K 的 Rockbox 定制固件，针对 M3K 的屏幕、按键和使用体验进行了适配。
Hi-M3K is a customized Rockbox firmware for the FiiO M3K, adapted and optimized for its display, controls, and overall user experience.

## 主要功能

全新的 Hi-M3K 图形化主界面
New Hi-M3K graphical home screen

Hi-M3K 风格菜单布局
Hi-M3K-style menu layout

自定义主界面壁纸及透明图标
Custom home-screen wallpaper and transparent icons

统一的二级菜单视觉风格
Consistent visual style across secondary menus

优化中文字体与符号显示
Improved Chinese font and symbol rendering

支持中文歌曲名称和艺术家信息
Chinese song title and artist display support

优化 CoverFlow 滑动流畅度
Improved CoverFlow scrolling performance

CoverFlow 支持外置及内嵌专辑封面
External and embedded album artwork support in CoverFlow

优化播放界面的封面显示与文字滚动
Improved album artwork rendering and text scrolling on the playback screen

新增基于专辑封面的锁屏界面
Album-art-based lock screen

锁屏界面显示本地时间、电量和播放进度
Local time, battery level, and playback progress displayed on the lock screen

新增电子书阅读器
Built-in ebook reader

支持 EPUB 和 MOBI7 格式电子书
EPUB and MOBI7 ebook support

支持正文排版、翻页和阅读书签
Text layout, page navigation, and reading bookmark support

移除不必要的游戏文件，减小固件体积
Unnecessary game files removed to reduce firmware size
