## Hi-M3K v1.0.0

适用于 FiiO M3K 的 Rockbox 定制固件，针对 M3K 的屏幕、按键和使用体验进行了适配。

## 主要功能

全新的 Hi-M3K 图形化主界面

Hi-M3K 风格菜单布局

自定义主界面壁纸及透明图标

统一的二级菜单视觉风格

优化中文字体与符号显示

支持中文歌曲名称和艺术家信息

优化 CoverFlow 滑动流畅度

CoverFlow 支持外置及内嵌专辑封面

优化播放界面的封面显示与文字滚动

新增基于专辑封面的锁屏界面

锁屏界面显示本地时间、电量和播放进度

新增电子书阅读器

支持 EPUB 和 MOBI7 格式电子书

支持正文排版、翻页和阅读书签

移除不必要的游戏文件，减小固件体积
